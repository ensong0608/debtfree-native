# Public app name review

**Status:** No public name selected. No name or production identifier was changed.

## Recommendation

Do not lock `DebtFree` as the public listing name based only on the current code label. A quick store search found several current products using `DebtFree` or very close wording, including [Debt PayOff Manager](https://play.google.com/store/apps/details?id=com.irtiqa.debtfree), [Debt Payoff Planner & Coach](https://play.google.com/store/apps/details?id=com.debtfreecoach.app), [DebtFree: EMI & Loan Planner](https://play.google.com/store/apps/details?id=com.ebrahim.debtfree), and [Debt Payoff Tracker - DebtFree App](https://apps.apple.com/us/app/debt-payoff-tracker-debtfree/id6755614652). This indicates store-listing overlap; it is not a legal finding that the owner cannot use the name.

The following are first candidates for the owner to react to. Exact-name Google Play/App Store searches in this pass returned no matching listings for these spellings; that does not establish availability, domain ownership, or trademark clearance.

A store subtitle such as “Debt and Budget Planner” could explain the app's manual tracking scope. Keep the internal `DebtFree` name for development until the owner selects a public name.

The US Patent and Trademark Office says a comprehensive clearance search includes federal and state trademark databases and internet use, and may require more than an exact-word search. Treat any candidate here as preliminary and have the final choice cleared for the owner's intended launch markets before purchasing a domain or locking the Android package ID: [USPTO search guidance](https://www.uspto.gov/trademarks/search/federal-trademark-searching).

## Decision needed before the Android listing build

Choose or revise a public display name. After that, confirm the Android application ID in the Play Console, choose the URL scheme, and update the production config. The current app name and package remain sandbox values until those decisions are made.
