# Ubuntu font assets

Ubuntu Regular (400), Medium (500), and Bold (700) are downloaded from the Google Fonts Ubuntu distribution at `fonts.gstatic.com/s/ubuntu/v21/`. Font licensing is retained in `UFL.txt` (Ubuntu Font Licence 1.0, from the Google Fonts repository).

The Signature green study embeds these font files and the license text directly for offline review. Keep the font license with redistributed assets.
