# Montserrat preview fallback

Montserrat 400 / 500 / 700 is included under the SIL Open Font License in `OFL.txt`. Files came from the official Google Fonts CSS distribution.

Uphold identifies Proxima Nova in its public brand guidelines at https://uphold.design/. Proxima Nova files were not available locally for this review. The Uphold-inspired study therefore explicitly labels Montserrat as its preview stand-in. This is a palette and typography-direction study, not an exact reproduction of Uphold's app or its interface design system. The BitLess identity is retained.

Font binaries and license text are embedded in the study and master gallery for offline review.
