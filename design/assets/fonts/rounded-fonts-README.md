# Rounded font comparison

Nunito, Quicksand and Rubik, in regular (400), medium (500) and bold (700), were retrieved from their official Google Fonts CSS distributions. The corresponding SIL Open Font License files from the Google Fonts repository are retained in each family directory.

`signature-rounded-fonts-2026-11-15.html` embeds the font binaries and license text for offline review. The master gallery retains those embedded fonts. The lightweight preview source under scratch uses the same Google Fonts font URLs for renderer compatibility; it is not the distributed master.
