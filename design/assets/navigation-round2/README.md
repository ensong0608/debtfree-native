# Navigation study icon sources

Unmodified official Lucide static SVG assets, version 0.468.0, ISC license notices retained in each SVG. Source: https://unpkg.com/lucide-static@0.468.0/icons/ .

All navigation symbols use the same 24-unit source grid, 2-unit rounded strokes and a 28px display box. The proposal embeds these assets as CSS masks so the interactive study has no runtime dependency or network requests. Application icons are not changed.
