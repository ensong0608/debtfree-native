App icon tiles

Choose a tile when setting a fixed launcher icon. System light/dark mode does not change the installed app icon.

Usage notes

  • Home header: use the mark beside the app title ?BitLess?.
  • Other app tabs: use the mark beside that tab?s title; keep ?BitLess? off those headers.
  • Welcome, splash, docs, or broad brand placement: use stacked or horizontal lockup.
  • Favicon, compact shortcut, or avatar: use mark-only. The SVG has a close crop for small placements.
  • Light and dark: Cobalt and Indigo each have explicit light/dark mark and wordmark colors; Inspire uses the current teal brand token.
  • Brand boundaries: keep financial category and risk colors out of logo artwork.

Generated lockups use outlined Ubuntu Bold wordmarks, so they stay consistent without installed fonts. The untouched supplied SVG remains available; the source Ubuntu Bold font and its license are included for future edits.

Source and file naming

The untouched supplied SVG is preserved as assets/bitless-logo-supplied.svg. Theme assets follow logo-[lockup]-[scheme].svg; app tiles use app-icon-[palette].svg. Transparent logo vectors are suitable for product headers, websites, and documents. No native app or theme code is changed by this kit.
